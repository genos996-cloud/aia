財團法人人工智慧科技推動基金會｜架構心法演示

標準化自動導入與成本判斷使用模型

企業導入 AI 的致命誤區，就是把大模型當作萬能解藥。本單元確立「認知與算力邊界」的 3 大任務分工，精確劃分確定性邏輯、機率性規律與人類最終裁量，把系統成本與風控鎖死在架構底層。

💡 企業進行 AI 落地前的三項成本與架構核心自問：
一、這件事需要「算力」還是「演算法」？ 凡是有固定數學公式、狀態轉移或欄位校驗的業務，硬套 LLM 就是在浪費 Token 與增加隨機幻覺風險。
二、輸出的隨機性會不會搞垮主資料庫？ 大模型的模糊語意必須強制通過結構化契約（JSON Schema）收斂，未經驗證絕不允許直接寫入系統骨幹。
三、出事了誰來承擔商業與法律責任？ 涉及核心定價、退款特許與不可逆重大決策，AI 只能提供情境推導，最終簽核責任永遠屬於實體人類。

1
第一層：確定性規則層（Deterministic Code）
核心定位：狀態明確、邏輯封閉、有唯一標準答案的業務邏輯。追求毫秒級響應、近乎零算力成本、百分之百可重現。
  • 適用領域本質： 核心金流四則運算、門市庫存扣減、組織獎金提撥、訂單狀態機切換、正規表達式與資料表綱要驗證。
  • 工程實現手段： 純程式碼實現（Python, TypeScript, SQL, 有限狀態機 FSM），構建全系統的高速主執行通道（Fast-Path Pipeline）。
  • 交付檢驗指標： 端對端延遲 < 5ms，呼叫成本為 $0，零隨機幻覺。全鏈路單元測試覆蓋率需達 100%。
嚴格紅線： 嚴禁拿大語言模型處理基礎數值精算、定價公式與死板字串替換。凡有確定性演算法者，模型絕對不得介入。
本層交付成果：高內聚的確定性邏輯模組，為企業系統提供最堅固、可預期且零成本的運行骨幹。
2
第二層：機率性規律層（Probabilistic Engine / API）
核心定位：處理有跡可循但無固定死公式的場景。以嚴密的結構化契約將模糊語意收斂為系統可消費的確定資料。
  • 適用領域本質： 非結構化合約資料擷取、模糊意圖辨識、開放情境語意檢索、教學對話狀態追蹤與自然語言輔助生成。
  • 工程實現手段： 串接前沿 LLM 與多模態模型，透過 MCP 協議封裝工具，嚴格實施 Few-shot 範例與 JSON Schema 強制型別校驗。
  • 交付檢驗指標： 7×24 高可用服務，以結構化輸出全面消弭隨機發散，每一筆模型調用的 Token 消耗具備精確度量。
嚴格紅線： 模型端輸出永遠視為「未受信任之外部輸入（Untrusted Input）」，未經後端 Schema 驗證前，絕不允許直接寫入核心資料庫。
本層交付成果：標準化的語意處理慢軌管線（Slow-Path Pipeline），實現智慧理解與系統主庫安全邊界的物理隔離。
3
第三層：混沌意志層（Human Governance & Judgment）
核心定位：商業定價、資安妥協、法律合規、例外處理及政治角力等不存在標準演算法的領域。
  • 適用領域本質： 面對充滿衝突與不確定性的經營情境，演算法無法定義何為「絕對正確」，必須依賴人類責任負擔與裁量。
  • 工程實現手段： 導入半人馬（Centaur）架構，在系統關鍵交易節點設計不可跳過的 Human-in-the-loop 斷點與雙向授權閘道。
  • 交付檢驗指標： 系統負責窮舉與推導多套情境的邊際衝擊，最終裁量權與法律責任牢牢鎖定在實體負責人手中。
嚴格紅線： 涉及巨額資金劃撥、合約重大簽署或不可逆系統清算，絕對禁止授予 AI 自主代理（Autonomous Agent）執行權限。
本層交付成果：專家與 AI 系統的協同簽核通道，明確劃定技術推導與商業法律決策的最終責任邊界。
